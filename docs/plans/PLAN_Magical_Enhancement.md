# [PLAN] 마법의 소라고동(Magical Conch) 기능 고도화 및 프리미엄 리뉴얼

## 1. 개요
현재의 '마법의 소라고동' 서비스는 단순 무작위 답변 방식을 사용하고 있습니다. 이를 현대적인 금융 AI의 정체성과 결합하여, 실시간 시장 데이터와 거대 언어 모델(LLM)이 융합된 **'신비로운 지능형 투자 조언자'**로 탈바꿈시키고자 합니다.

## 2. 핵심 강화 기능 (Functional Enhancements)

### 2.1 AI 기반 맞춤형 조언 (AI-Driven Logic)
- **랜덤 답변 탈피**: 단순 배열에서 무작위 문장을 선택하는 대신, `Groq API`를 호출하여 실시간으로 생성된 조언을 제공합니다.
- **시장 데이터 연동**: 현재 분석된 '마켓 센티먼트 점수(공포/탐욕 지수)'를 AI 프롬프트에 주입하여, 하락장에서는 보수적인 조언을, 상승장에서는 긍정적인 조언을 하도록 설계합니다.
- **종목 검색 기능**: 사용자가 특정 티커(예: TSLA, AAPL)를 입력하면 해당 종목의 최근 기류와 시장 상황을 종합적으로 판단하여 조언합니다.

### 2.2 페르소나 시스템 (Mystical Persona)
- **예언자 페르소나**: 단순한 봇이 아닌, "금융의 심해를 읽는 마법의 소라고동"이라는 컨셉을 유지하며 신비로운 말투와 전문적인 통찰을 동시에 제공합니다.

---

## 3. 디자인 리뉴얼 (Design & Aesthetics)

### 3.1 비주얼 테마: '네오 사이버 미스틱'
- **Glassmorphism**: 반투명한 유리 소재의 UI를 활용하여 깊이감과 고급스러움을 부여합니다.
- **Neon Glow**: 포인트 컬러(Buy: #FF007A, Sell: #00F0FF)에 네온 발광 효과를 추가하여 미래지향적인 분위기를 조성합니다.
- **Dynamic Background**: 오로라 형태의 그라데이션 애니메이션 또는 입자(Particle) 효과가 배경에서 부드럽게 움직이도록 구현합니다.

### 3.2 고품질 애니메이션
- **Lottie/SVG Interaction**: 소라고동을 클릭했을 때 단순한 흔들림이 아닌, 마법의 에너지가 모이는 듯한 파티클 효과와 빛의 연출을 추가합니다.
- **Thinking State**: AI가 답변을 생성하는 동안 사용자에게 시각적인 '지루하지 않은 기다림'을 주기 위한 신비로운 대기 애니메이션을 구현합니다.

---

## 4. 기술 사양 (Technical Specifications)

### 4.1 백엔드 구조
- **Model**: `llama-3.1-8b-instant` (Groq API)
- **Endpoint**: `POST /api/v1/magical/consult`
- **Context Injection**:
  - `sentiment_score`: 실시간 시장 데이터
  - `user_query`: 사용자 입력 종목/질문
  - `mode`: BUY/SELL 선택 모드

### 4.2 프론트엔드 기술
- **Vanilla JS + Tailwind CSS**: 최적의 퍼포먼스와 커스텀 디자인을 위해 사용.
- **Fetch API**: 비동기 통신으로 페이지 새로고침 없이 빠른 응답 구현.

## 5. 기대 효과
- **사용자 참여(Engagement) 유도**: 단순 재미 요소를 넘어 실질적인 시장 데이터를 반영함으로써 사용자가 대시보드에서 더 긴 시간을 머물게 합니다.
- **브랜드 가치 향상**: Stock Lab만의 독특하고 프리미엄한 AI 정체성을 사용자에게 각인시킵니다.
